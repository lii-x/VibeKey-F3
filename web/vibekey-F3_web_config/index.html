关于 VibeKey-F3 Web
基于 Web Serial API 的网页版配置工具，无需安装驱动，浏览器直接配置设备。
本页 UI 对齐 VibeKey-F3 Studio 桌面端工作台（侧边导航 + 微信绿主题）。
网页端 vs 桌面端 (VibeKey-F3 Studio)
• 桌面端 Studio（Qt）：按键配置、运行状态监控、OTA 固件升级、灯效、系统托盘、固件更新提醒等完整功能。
• 网页端：免安装，插上 USB 即可读取/写入配置、升级固件，适合临时改动与分享给朋友使用。
使用说明
1. 使用 Chrome / Edge 打开本页（Web Serial 仅支持 Chromium 内核浏览器）
2. 设备通过 USB 连接电脑
3. 点击右上角"连接设备"，在弹出的串口列表中选择设备
4. 读取配置 → 修改 → 写入配置
提示：右上角按钮可切换 深 / 浅 / 跟随系统 三种主题。
按键配置页：单击卡片打开编辑弹窗；按住拖动卡片可调整位置，拖过之后卡片右上角会出现 ↻ 按钮，点它恢复默认位置。
