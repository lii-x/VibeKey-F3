## v35 ★ 下载版本号修复：加 GitHub 兜底数据源

**症状**：线上 CTA 按钮文案停在 `下载 Windows 版 v1.1.4`，而 Gitee / GitHub
其实都已发布 `studio-v1.1.5`（2026-10-06）。

**根因**：按钮上的版本号是**写死的兜底文案**，真正的最新版由 JS 拉
`gitee.com/api/v5/repos/.../releases` 后覆盖。而 **Gitee API 按来源 IP 限流**，
超限直接 `403 Forbidden (Rate Limit Exceeded)` —— 本机（含沙箱出口 IP）实测
连续多次都是 403。于是 fetch 进 `.catch` 分支静默保留写死版本，
**表现就是版本号永远停在旧值**。JS 的版本挑选逻辑本身没问题
（喂模拟数据能正确挑出 `studio-v1.1.5`）。

**修法**：
1. 把 `data-gh-repo`（HTML 里本来就有，只是没用）接上，做成
   **Gitee → GitHub 顺序回退**：第一个成功的源即止，全失败才用兜底文案。
   两个源的 API 返回结构一致（`tag_name` / `assets[].name` /
   `browser_download_url`），共用同一个 `pick()`。
2. 写死的兜底 href/文案从 `v1.1.4` 更新到 `v1.1.5`（保证无 JS 时也不指旧版）。

**验证**（真浏览器 + CDP，四种场景全过）：
| 场景 | 预期 | 实测 |
|---|---|---|
| Gitee 限流 + GitHub 通 | 回退 GitHub，显示 v1.1.5 | ✓ 网络跟踪：先 Gitee(失败) → 再 GitHub(200) → v1.1.5 |
| 两源都通 | **只**请求 Gitee，忽略 GitHub | ✓ 仅 1 个请求（Gitee） |
| 两源全挂 | 退到 HTML 兜底 v1.1.5，按钮仍可点 | ✓ 文案 v1.1.5、`<a>` 可点 |
| 版本号比较 | `1.1.10 > 1.1.9`（按数字非字符串） | ✓ 逐段比数字 |

**留给以后的坑**：Gitee 的限流是**来源 IP 维度**的，会命中整个公司/校园网/代理出口 ——
不是"偶发抽风"，是常态。任何把 Gitee 当唯一数据源的设计都要预置回退。

## ★ 关键技术约束（源码里仍有保留）

这几条是**看代码看不出来、删了就会再踩**的，因此留在源码注释中；
此处再列一份索引。

### 等比缩放的数学前提

要让"缩放后正好铺满"，必须满足 `画布宽 × k = clientWidth`，
而 `k = clientWidth / 1280` ⇒ **画布宽恒等于 1280px**（写死，不能写 100%，
否则得到 `clientWidth²/1280`）。

### 为什么用 `clientWidth` 而不是 `window.innerWidth`

`clientWidth` 已扣纵向滚动条（桌面 Edge 约 15px）。用 `innerWidth` 算 k
会让内容比可用区宽 15px → 触发横向滚动条 → 又改变可用宽 ⇒ **反馈循环（抖动）**。

### 判据与 CSS 断点必须自洽（1281px 边界 bug）

JS 用 `clientWidth < 1280` 判定，CSS 覆盖区若也写 `@media (max-width: 1280px)` 会错位：
窗口 1281px 时 `clientWidth=1266` 触发缩放，但媒体查询不匹配，
画布拿不到 `width:1280` 仍是 100%(=1266) ⇒ 桌面宽度下平白缩小。
**修**：CSS 阈值放宽到 **1400px**，判定权只交给 JS 的 `.vk-fixed` 类。

### `transform` 的两个副作用

- **创建包含块** ⇒ 内部 `position: fixed` 退化为相对该元素；窄屏下 `.nav` 改
  `absolute`，**代价是不再吸顶**。
- **不撑布局高度** ⇒ 需外层 `.vk-scale-outer` 用 `height = 画布 offsetHeight × k` 补回。

### `clamp(a, Nvw, b)` 认视口宽不认容器宽

缩放模式下必须逐条钉死成上限值，否则手机下全取下限、缩完标题偏小。全站 8 处：
`h1` / `hero-sub` / `sec-head h2` / `sec-head p` / `split-txt h3` / `split-txt > p` /
`narrow .lead` / `cta h2`。**以后新增 `clamp` 必须同步补一条**。

### 覆盖区必须放在 `style.css` 最末尾

同优先级下后来者居上，否则会被前面的原始 `@media` 断点盖回去。

### `.rv` 滚动动画在缩放模式下必须整体 `opacity:1`

（可触发区域变窄，易误判"没加载"。）

### 栅格一律 `minmax(0, 1fr)`

栅格默认 `min-width:auto`，子项里的不换行内容（如 `h1` 的 `AI&nbsp;效率`）
会把列撑宽导致整行溢出。

---

## 验证方法（沉淀，勿丢）

### 「双视口逐项计算样式比对法」

在 **1280** 与 **390** 两个视口各抓同一批 42 选择器 × 17 属性
（`gridTemplateColumns`/`gap`/`padding`/`fontSize`/`width`/`height`/…）逐项 diff，
差异即"响应式残留"。达标线：**实质差异 0**。

> ⚠️ 基线视口**必须取 1280（=设计宽）**，取 1440/1281 会因 `.wrap` 居中或滚动条扣宽
> 产生 margin/width 假差异，把真 bug 淹没（第一轮被骗出 42 条假差异）。

### 宽度横扫

320…1920 共 20 档，断言：①是否进入缩放 ②`k == clientWidth/1280`
③外层高 ≈ 画布高 × k（验证无底部留白）④无横向滚动 ⑤非装饰元素零溢出。

### 其他

- CSS 括号配平 + `/*`/`*/` 配对 + U+FFFD 检查 + 内联 JS `node --check`。
- 触屏滚动/真实鼠标行为须用 CDP 真实鼠标驱动测（虚拟时钟下
  `--screenshot`/`getComputedStyle` 不插值帧）。
- 断言样式前先查 `document.styleSheets.length`——外链 CSS 没加载时所有
  `getComputedStyle` 断言都是"假通过"。
